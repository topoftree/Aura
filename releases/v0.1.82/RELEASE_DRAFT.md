## Release notes

Initial public release of Aura, version 0.1.82 (83).

- Add installed Steam game update checks, Library update entry, side notifications and Messages confirmation.
- Minimize the Steam main window once the selected game window appears.
- Gate optional diagnostic collection behind Advanced Debug mode.
- Remove startup particles and darken the dark-mode glass and edge effects.
- Add display-update and thread timing diagnostics; no verified Stardew FPS or ESync fix is claimed.

Android 14+, ARM64. Signed release build with R8 and resource shrinking. End running game sessions before updating.
